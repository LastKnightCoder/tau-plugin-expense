# 记账本

一句话记下每笔花费，随时看到「这个月还能花多少」。月历、分类预算和近半年的图表帮你看清钱花在哪，AI 帮你找出能省的地方。

## 能做什么

- **一句话记账**：写「午饭 牛肉面 28」回车就记下了，金额和分类自动识别；开头写「昨天」「前天」就记到那天。认不出分类时点一下，记过一次后同样的写法会自动归类，也可以让 AI 来归类。
- **还能花多少**：页面顶部显示本月剩余预算、剩下每天最多能花多少，进度条上的竖线是今天的时间进度，花得比时间快就会提醒你。
- **月历**：每天花了多少、最大的一笔是什么；格子底部的彩条长短表示花了多少（满半格是日均额度），颜色表示花在哪些分类。点某一天，右边流水只看那天。
- **分类预算**：每个分类一行，显示已用和预算、是否花得偏快或已超，以及比前 3 个月平均多花还是少花。点一个分类，日历和流水只看这一类。
- **固定支出**：房租、话费、会员这类每月不变的，在设置里填一次，到日子自动记一笔。它们单独标出，不计入日历和日均，避免把日常开销看偏。
- **回顾**：近 6 个月每月的支出构成，以及一周里哪天花得最多。点某个月的柱子可以翻到那个月。
- **AI**：「提醒」告诉你剩下几天每天能花多少、哪类要收着点；「月度复盘」找出比平时多花在哪，给出能省多少的建议。
- **首页卡片**：在「今日」首页直接看到本月余额，记一笔。
- **手机上用**：Android、iOS 有专门的触控界面。按住麦克风说「午饭二十八，打车回家三十六」，一次记好几笔；左滑一笔可以修改或删除，月历、分类和回顾各是一页。

## 开始使用

1. 在插件中心安装并启用「记账本」。
2. 打开插件详情的「设置」，按自己的情况改一改每个分类的月预算，再把房租、会员这类固定支出填进去。
3. 点侧边栏的「记账」，每花一笔就写一句。手机上在「我的」顶部找到「记账本」，今天页也有一张记账卡。

## 常见问题

**AI 能看到什么？** 只有各分类的金额和你写的备注文字，不读取你的其他笔记。AI 使用你为「对话功能」分配的模型，第一次使用时会询问授权，可以在插件详情的「权限」中撤销。不用 AI 也完全可以记账。

**手机上的语音用的是什么识别？** 沿用 Tau「我的 › 语音 › 语音输入」里选的识别方式。第一次按住说话时会询问是否允许记账本使用语音输入，可以在插件详情的「权限」中撤销。没配 AI 模型时也能用，按句子拆开、用本地规则归类。

**数据会同步吗？** 会。流水和设置存在笔记库里，随笔记库一起同步。

**删掉一个分类，它的流水去哪了？** 移到「其他」，金额不会丢。

**预算不知道怎么定？** 先记一两个月，再到设置里点「按前 3 个月平均填入」，在这个基础上往下调一点。
